- Pixel 7 AVD
- Android 17 / API 37
- x86_64、16 KB page size
- 1080 × 2400、420 dpi
- Media3 1.10.1

## 自动验证

- 36 个 JVM 测试通过，0 failure / 0 error / 0 skipped。
- 18 个 Android 设备测试通过，0 failure / 0 error / 0 skipped。
- 设备测试覆盖 Room v5→v6 封面字段迁移、此前全部 v2→v5 迁移、聚合查询、中文全文搜索、阅读位置、书签/高亮/批注、Compose UI、对话记忆边界和 Media3 播放。
- 新增系统中文 TTS 设备测试：应用启动时在 IO 线程预热中文引擎，固定无敏感中文段落在预热后 5 秒内生成非空本地音频文件。
- Lint Debug、Debug APK、R8/资源裁剪 Release 构建均纳入最终验证。

## 手动冒烟

- 使用固定无版权 TXT 通过系统文件选择器导入，正确识别 2 章。
- 书籍主页只保留封面、进度、继续阅读、立即朗读和功能入口；功能内容不再纵向堆在主页。
- 章节目录从阅读器点击打开独立页面；书签和批注继续打开各自独立页面，无抽屉或左右滑动切换。
- 聊天阅读保持原文顺序：旁白为居中窄卡片，角色对话有稳定头像、颜色和位置；原文模式仍为连续正文。
- 默认应用主题为近黑、蓝灰层次和橙色强调；状态栏和导航栏图标在深色背景下可见。
- 设置主页拆为外观、阅读默认值、LLM、配音、数据与备份、诊断六个点击式入口。
- 书籍主页、阅读器、目录和设置主页均在 1080×2400 下完成截图检查；临时截图未提交仓库。

## 配音验证边界

- Android 本地 TTS 首段生成由自动设备测试验证，不上传书籍正文。
- Edge 客户端已实现 8 秒连接、12 秒首帧、30 秒总时限、240 字硬上限、阶段化错误、落盘前解码校验和 30 分钟失败冷却。
- 设置中的“真实负载试听”使用固定约 150 字测试文，并要求生成、解码和实际播放后才显示通过。
- 为避免在自动验收中向外部服务发送任何书籍内容，本轮没有替用户主动点击真实 Edge 试听；该项需用户在知情情况下手动触发。

## 仍需实体条件

- 蓝牙媒体键、真实耳机拔出和厂商音频焦点行为需要实体 Android 设备。
- Fish Audio、OpenAI-compatible 服务需要用户自己的有效凭据，本次未使用真实密钥或产生费用。
- 本机只有 API 37 镜像；API 26 与 API 35 需要在 CI/补充 AVD 中验证。

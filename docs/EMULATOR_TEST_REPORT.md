# v0.5 虚拟机调试记录

日期：2026-07-22

## 环境

- Pixel 7 AVD
- Android 17 / API 37
- x86_64、16 KB page size
- 1080 × 2400、420 dpi
- Media3 1.10.1

## 自动验证

- 36 个 JVM 测试全部通过。
- 16 个 Android 设备测试全部通过，覆盖 Room v4→v5 迁移、聚合查询、中文全文搜索、阅读位置、书签/高亮/批注、Compose UI、对话记忆边界和 Media3 播放。
- Media3 设备测试使用本地 WAV 与 manifest，验证正文块映射、后台播放、1.5 倍速、15 分钟睡眠定时，以及下一章无完整缓存时停止提示。
- Lint 0 error，Debug 和启用 R8/资源裁剪的 Release 构建通过。

## 手动冒烟

- 系统文件选择器导入 TXT、章节识别、书架继续阅读和书籍详情。
- 聊天/原文模式切换与重启恢复。
- 原文精确选区、系统复制菜单、标记/批注、高亮渲染、编辑与删除入口。
- 目录、书签、批注抽屉；纸白/羊皮纸/夜间主题和单书样式覆盖。
- 任务中心筛选、失败详情、重试、取消和七天终态记录。
- 未配置 LLM 时安全失败，不发送付费请求。
- Edge TTS 在虚拟机网络中进入分段生成；网络未完成首段时，超时、重试与取消均正常落库。

## 调试中修复

- MockWebServer 集成测试显式确认本机 HTTP，符合明文地址策略。
- 为 API 37 SQLite 的中文 FTS 分词差异增加已索引内容兼容查询。
- 阅读设置底部面板支持内部滚动，保证所有控件可达。
- 夜间预设同步覆盖阅读顶部与底部工具栏。
- MediaController 操作显式切换主线程，manifest 读取放入 IO；控制器释放也回到主线程。

## 仍需实体条件

- 蓝牙媒体键、真实耳机拔出和厂商音频焦点行为需要实体 Android 设备。
- Fish Audio、OpenAI-compatible 服务需要用户自己的有效凭据，本次未使用真实密钥或产生费用。
- 本机只有 API 37 镜像；CI 设备矩阵已配置 API 26 与 API 35，供手动或每周任务验证。

# Legado 行为参考记录

章境 v0.6 仅把 Legado（GPLv3）作为阅读产品行为参考。参考包在仓库外的临时目录构建，Debug 包 `io.legado.app.debug` 已安装到 Pixel 7 虚拟机。实现过程中没有复制其 Kotlin、XML、图片资源、字符串表、翻页算法或书源规则；构建产物和临时截图也不进入本仓库。

## 虚拟机观察

- 书架使用高信息密度封面列表，顶部搜索，卡片突出书名、章节和来源信息。
- 阅读时中央点击呼出工具栏；底部先显示章节进度，再提供目录、朗读、界面和设置等高频入口。
- 目录、书签、书籍信息、搜索和朗读控制具有清楚的页面层级，返回路径容易理解。
- 本地导入首次要求公共文件夹授权，首次启动还会连续出现隐私、帮助和密码提示；这些步骤对章境的纯本地 TXT 导入没有价值。
- Legado 书架标签可以左右滑动切换；这与章境用户指定的点击式导航冲突，因此不采用。

## 章境的独立实现决定

- 使用章节 ID 与正文字符偏移保存位置，避免排版变化导致进度丢失。
- 保留中央点击和底部高频入口，但目录、书签、批注、搜索、界面和设置全部点击打开独立 Compose 路由，不用抽屉、整页底部面板或左右滑动。
- 全局阅读样式作为默认值，允许单本小说覆盖并随时恢复继承。
- 后台播放支持进度恢复、倍速、媒体控制、朗读段落跟随和睡眠定时。
- 精品配音不可用时优先使用 Android 中文 TTS；自动朗读不调用 LLM、Fish Audio 或 OpenAI-compatible 服务。
- 阅读器只预取本地相邻章节，不隐式访问网络或产生付费 TTS 请求。
- 聊天阅读中的旁白保持原文顺序，但使用独立居中卡片；角色气泡按角色稳定分侧。

## 明确排除

书源脚本、自定义抓取规则、在线发现、RSS、漫画、EPUB、主题包导入、仿真翻页、复杂背景导入和 Legado 私有数据格式兼容。

# Legado 行为参考记录

章境 v0.5 仅把 Legado（GPLv3）作为阅读产品行为参考。实现过程中没有复制其 Kotlin、XML、图片资源、字符串表、翻页算法或书源规则。

独立实现采用的通用交互原则：

- 使用章节 ID 与正文字符偏移保存位置，避免排版变化导致进度丢失。
- 将目录、书签和批注集中到阅读导航抽屉。
- 全局阅读样式作为默认值，允许单本小说覆盖并随时恢复继承。
- 后台播放支持进度恢复、倍速、媒体控制、朗读段落跟随和睡眠定时。
- 阅读器只预取本地相邻章节，不隐式访问网络或产生 TTS 费用。

明确不在 v0.5 中实现：书源脚本、自定义抓取规则、在线书城、主题包导入、仿真翻页和 Legado 私有数据格式兼容。

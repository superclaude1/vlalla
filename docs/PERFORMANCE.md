# 性能基线与发布门槛

每个候选版本在同一台 API 34 设备、同一份测试小说上各执行五次，丢弃第一次预热结果，记录中位数。

| 场景 | 测量起点 | 测量终点 | 发布门槛 |
| --- | --- | --- | --- |
| 冷启动 | 点击启动图标 | 书架首帧可交互 | 不高于上一版本中位数的 110% |
| 书架加载 | Room 查询开始 | 聚合书架列表显示 | 查询次数固定为 1，耗时不回退超过 10% |
| 长列表滚动 | 首次连续滚动 | 滚动到列表末尾 | 不出现可复现卡死，慢帧比例不回退 |
| 书籍详情 | 点击书卡 | 详情主要操作可用 | 不高于上一版本中位数的 110% |

使用 Android Studio System Trace 和 Layout Inspector 保存原始记录；CI 负责功能质量门禁，性能结果在发布说明中记录设备、数据规模和四项中位数。任何超出门槛的变化必须修复，或在发布说明中说明原因并单独批准。
